Bypass proxy (ru)

Российские сайты напрямую, остальное через SOCKS5

Как работает

Расширение смотрит на имя хоста каждого запроса и выбирает маршрут. Российские домены из списка geosite и ваши собственные правила идут напрямую, всё остальное — через SOCKS5.

Если SOCKS5 не задан, используется прокси, настроенный в самом Firefox. Самостоятельно переключаться на прямое соединение расширение не станет.

How it works

The extension looks at the hostname of every request and picks a route. Russian domains from the geosite list and your own rules go direct, everything else goes through SOCKS5.

If SOCKS5 is not set, the proxy configured in Firefox itself is used. The extension will not fall back to a direct connection on its own.

SOCKS5

Указываются хост и порт, логин и пароль — необязательно. Переключатель «DNS через прокси» включён по умолчанию: DNS-запросы уходят прокси, а не провайдеру. Выключите его, если прокси не умеет резолвить имена.

Если прокси недоступен, запросы, которые должны были через него пойти, вернут обычную сетевую ошибку.

SOCKS5

You provide a host and a port, with username and password optional. The “DNS through proxy” toggle is on by default: DNS queries go to the proxy instead of your provider. Turn it off if the proxy cannot resolve names.

If the proxy is unreachable, requests that were meant to go through it return a regular network error.

Список доменов

Список русских доменов берётся из файла geosite.dat — скомпилированного списка доменных имён по категориям. Расширение выбирает российские категории, разбирает файл локально и хранит результат.

Файл скачивается один раз, дальше обновляется по расписанию: каждый день, раз в неделю или раз в месяц — как выбрано в настройках. При неудачном скачивании повтор делается позже, а предыдущий список продолжает работать.

Domain list

The list of Russian domains comes from geosite.dat, a compiled list of domain names grouped by category. The extension picks the Russian categories, parses the file locally and stores the result.

The file is downloaded once, then refreshed on a schedule: daily, weekly or monthly, as chosen in the settings. If a download fails it is retried later, and the previous list keeps working.

Свои правила

Кроме автоматического списка можно добавить свои правила. Они тоже идут напрямую.

  • example.com — хост и все поддомены, любой путь
  • *.local — только поддомены, сам домен через прокси
  • https://site.ru/path — только этот префикс URL
  • *://*.cdn.net/* — любая схема, поддомены, любой путь

Custom rules

Besides the automatic list you can add your own rules. They go direct as well.

  • example.com — the host and all subdomains, any path
  • *.local — subdomains only, the bare domain goes through the proxy
  • https://site.ru/path — this URL prefix only
  • *://*.cdn.net/* — any scheme, subdomains, any path

Android

Расширение работает в Firefox для Android. Настройки те же: SOCKS5 и расписание обновления списка настраиваются так же, файл скачивается автоматически.

Firefox на Android не устанавливает расширения из файлов — только из AMO.

Android

The extension works in Firefox for Android. The settings are the same: SOCKS5 and the refresh schedule are configured the same way, and the file is downloaded automatically.

Firefox on Android does not install extensions from files — only from AMO.

Приватные окна

Расширение работает и в приватных окнах: правила те же, настройки общие с обычным режимом.

Private windows

The extension works in private windows too: the same rules apply, and the settings are shared with regular browsing.
